Night Shift, který nezmizí

Odpojíš monitor nebo se vypne obrazovka a Night Shift je pryč. V nastavení svítí „zapnuto“, ale obrazovka je zase modrá. nightshift-fix filtr automaticky vrátí.

Proč se to děje

Při každé změně konfigurace displejů (odpojení, připojení, uspání obrazovky, probuzení Macu) macOS resetuje barevné gamma tabulky. Služba CoreBrightness, která Night Shift řídí, je pak někdy nepoužije znovu. Stav „zapnuto“ zůstane, ale filtr zmizí. Proto chybu obvykle spraví ruční vypnutí a zapnutí.

Jak to funguje

1 · Posloucházměny displejů a uspání nebo probuzení obrazovky.
2 · Pamatuje sijestli byl Night Shift zapnutý ještě před změnou.
3 · Počká 2 snež se displeje usadí.
4 · ObnovíNight Shift rychlým vypnutím a zapnutím, ale jen když byl předtím zapnutý.

Neupravuje plán, intenzitu ani jiná nastavení. Používá stejnou systémovou třídu CBBlueLightClient jako Ovládací centrum.

Instalace

Potřebuješ Xcode Command Line Tools (xcode-select --install).

git clone https://github.com/hugomach/nightshift-fix.git
cd nightshift-fix
./install.sh

Skript zkompiluje helper do ~/.local/nightshift-fix/, zaregistruje LaunchAgent a hned ho spustí. Pak se spouští automaticky po každém přihlášení.

Ověření

launchctl list | grep nightshift-fix          # PID = běží
log stream --predicate 'process == "nsfix"'   # odpoj/připoj monitor

Odinstalace

Ze složky repozitáře:

./uninstall.sh

Nebo ručně, bez repozitáře:

launchctl bootout gui/$(id -u)/com.user.nightshift-fix
rm ~/Library/LaunchAgents/com.user.nightshift-fix.plist
rm -rf ~/.local/nightshift-fix

V systému po tom nic nezůstane a nastavení Night Shiftu se nezmění.

Co se kam instaluje

~/.local/nightshift-fix/nsfixzkompilovaný helper
~/.local/nightshift-fix/nsfix.mkopie zdrojáku
~/Library/LaunchAgents/com.user.nightshift-fix.plistautomatické spuštění po přihlášení

Řešení problémů

Filtr se pořád ztrácí

Zkontroluj, že helper běží. Pokud se monitor probouzí pomalu, zvyš v src/nsfix.m prodlevu 2 * NSEC_PER_SEC a spusť znovu ./install.sh.

Obrazovka krátce problikne

To je záměr: právě rychlé vypnutí a zapnutí filtr obnoví.

Po aktualizaci macOS to přestalo fungovat

CBBlueLightClient je privátní API Applu. Odinstaluj helper a založ issue.
